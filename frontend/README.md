# Frontend foundation

The planned client is TypeScript with published Fancy UI and supported package
contracts. The persistent Agent Panel and dynamic User Panel have no page-based
navigation. The user approved **A — Calm ledger with dark mode support** in the
Maipa Design ArtBoard. See [approved direction](../docs/design-direction.md) for
both token sets, System/Light/Dark preference behavior and shared interactions.
The scaffold must use verified published package/tooling contracts and preserve
backend authority. No UI implementation or release acceptance is claimed by
the design approval alone.

The workspace shell now uses published Fancy Card/Button/ResizablePanels and
initTheme/useTheme, with both approved palettes mapped to Fancy semantic tokens.
`npm run check` enforces frontend alignment before10Node tests/typecheck/build.
The Genie development site serves the built UI and real Django session API at
https://maipa.gen/. No provider runtime or finance/login/admin workflow is
claimed complete; theme browser interactions and full app acceptance are checked
separately from static markup.
